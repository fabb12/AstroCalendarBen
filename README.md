# AstroCalendario di Ben

App web (PWA) in italiano e in inglese per l'osservazione astronomica
amatoriale: cosa succede in cielo stasera, se si vede da casa tua, dove
guardare e come puntarlo col telescopio. Funziona anche senza rete, senza
account e senza server: i calcoli avvengono sul dispositivo.

- **Apri l'app**: <https://fabb12.github.io/AstroCalendarBen/>
- **Canale YouTube**: [@astroben2017](https://www.youtube.com/@astroben2017)
- **Guida**: [`guida.html`](guida.html) (in inglese [`guida-en.html`](guida-en.html))

## Provarla in locale

Non c'è nessuna build: basta un server statico nella cartella.

```sh
python3 -m http.server
```

e poi <http://localhost:8000/>.
